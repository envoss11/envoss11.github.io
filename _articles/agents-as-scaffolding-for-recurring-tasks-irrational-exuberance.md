> That is the pattern that I’ve found effective:  
> Prototype with agent-driven workflow until I get a feel for the workflow and what’s difficult about it  
> Refactor agent-driven control away, increasingly relying on code-driven workflow for more and more of the solution  
> End with a version that narrowly relies on agents for their strengths (navigating ambiguous problems like identifying code owners)
