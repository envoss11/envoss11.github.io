Decide which of two skills fits the idea below, then run it. Do not ask
clarifying questions first — capture the dump verbatim, do the work, open the
PR, and state what you assumed.

- **`data-analysis`** — the question could be answered by data somebody
  already publishes. Survey the sources, pull the best one, do first-pass EDA.
- **`experiment`** — something has to be run before there is anything to
  analyze: deploying and testing models, benchmarking tools against each
  other, measuring what a system actually does.

The test is one question: **does the data to answer this already exist
somewhere, or do you have to generate it?** Say which skill you picked, and
why, in the PR body.

Either way, keep the notebook minimal. It is the starting point of a pairing
session, not a finished piece: research deeply, write down little, and leave
the rest for the next interaction.
