{%- comment -%} Decorative backdrop — the sky the menu windows are open over. It has two faces, and both ship in the markup: CSS shows one and hides the other off `data-theme` on . See assets/css/site.css, section 10-skyline. Layers, back to front: .sky-stars five tiled pixel starfields + a dozen four-point sparkles [night] .sky-clouds three tiled cloud banks drifting at their own speeds [day] .sky-body the moon, or the sun, with a radial bloom behind it .sky-toggle the control laid over that sprite — the one live thing here .sky-comet a shooting star on a very long loop [night] .sky-birds a flock crossing on a very long loop [day] .sky-horizon haze, a far range, near foothills, and a castle Every sprite is a tiled data-URI or a handful of rects, so each theme costs one paint and no per-frame script. `aria-hidden` sits on the individual scenery layers rather than on .skyline, because the toggle lives in here too and has to stay reachable. The sprite is a sibling of the button rather than its content, so with no JS — where CSS withdraws the button entirely — the sky still looks exactly the same. {%- endcomment -%}
{%- comment -%} Waning gibbous: one pixel disc with a second disc bitten out of its left side. 32-unit viewBox rendered at exactly 3x, so every source pixel lands on a 3x3 block of device pixels with nothing in between. {%- endcomment -%} {%- comment -%} A 14px disc on the same 32-unit grid, with two rings of rays hung off it. The rings alternate rather than turn: rotating pixel art resamples it, and a two-frame swap is what the hardware this is imitating would have done. {%- endcomment -%}
{%- comment -%} Pointer-only, deliberately: `tabindex="-1"` and `aria-hidden`. This is the second control for one command — the nav carries the first, and the nav's is present at every width and in every theme, including all the widths where this one is withdrawn. Left in the tab order this would be the first stop on the page, ahead of the site's own navigation, and it would announce a command a screen reader has already been offered. So the keyboard and the reader get the nav toggle; the pointer gets the moon as well. The hint names the command, not the current setting — a menu says "Save", not "Not saved". Both strings ship and CSS drops the wrong one. {%- endcomment -%}
