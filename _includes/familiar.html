{%- comment -%} The familiar: a pixel cat that follows the cursor around the site. Both cats ship on every page. The choice can change on the About page without a reload, so both frame sets have to already be here — it is a few hundred bytes of path data each and no extra request, which is cheaper than the alternative. Nothing is visible until site.js summons one. The `aria-hidden` is not an oversight: the cat is decoration, and the real control is the pair of buttons on the About page, which carry the accessible name and the pressed state between them. A screen reader gets the toggle; it does not get told a cat walked past. Grid is 20x16 drawn at 3x, integer coordinates only, crisp edges — the same rules as icon.html and skyline.html. Every frame is bottom-aligned on the grid so the sprite does not hop when the pose changes. Colour lives in the --fam-* tokens, one set per cat per theme, so a white cat stays legible on parchment and a black one stays legible against the night sky. {%- endcomment -%}
